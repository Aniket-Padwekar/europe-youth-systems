# Europe's youth systems

Static site for GitHub Pages. No build step.

1. Create a public repo named `europe-youth-systems` and upload everything in this folder to `main` (index.html at the root).
2. Settings > Pages > Source: `main` / root. Live at https://aniket-padwekar.github.io/europe-youth-systems/
3. The map tiles (CARTO / OpenStreetMap) and player photos (Wikimedia Commons) load in the visitor's browser, so the page needs no keys.
